## Предметы

39 штук в `OBJECTS`. Категории: `animals`, `toys`, `tools`, `farm`, `nature`, `food`, `items`, `rare`.

Редкий: `golden_key` (шанс ~10 %, если на карте есть подходящая точка).

Чтобы добавить предмет:

1. PNG с прозрачностью → `assets/objects/<id>.png`
2. Запись в `OBJECTS` с `zones`
3. Убедиться, что на нужных картах есть спавны с пересекающимися зонами

## Зоны (логика «предмет стоит на своём месте»)

Примеры:

- лягушка, утка, рыбка, гусь, кораблик → `water` `pond` `reeds` `stream`
- вилы → `hay` `barn`
- лопата, грабли, лейка → `garden` `dirt` `fields`
- мяч, мишка, кукла, динозавр → `playground` `bench` `swing`
- кот → `house` `fence` `bench` `entrance`
- гриб, сова, белка, ёж → `trees` `forest` `stump`

Точки заданы массивом `SPAWNS[mapId]`: `{ id, nx, ny, zones }`.

## Аудио

Синтез Web Audio, файлов нет. Замок iOS снимается на первом тапе («Играть»).

## Демо без Telegram

Если нет `Telegram.WebApp` и хост не вызвал `init({ demo:false, userId })`:

- `userId = "demo"`
- попытки живут в localStorage
- на экране победы текст, что деньги не начисляются
- в payload поле `demo: true` — backend должен игнорировать такое начисление
