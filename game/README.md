# Ищи-найди — модуль для Family Bank

Мобильная Mini App игра: найти спрятанный предмет на большой карте.  
Не самостоятельный продукт — встраивается в уже существующий Telegram Mini App Family Bank.

## Запуск

Откройте `index.html` через статический сервер:

```bash
python3 -m http.server 8080 --directory .
```

Либо просто откройте файл в браузере (демо-режим).

На телефоне игра сразу в портрете: карта таскается пальцем, зум щипком, цель снизу.

## Документы

- [INTEGRATION.md](INTEGRATION.md) — как встроить, API победы/проигрыша, что хранить на сервере

## Стек

HTML + CSS + JavaScript. Без React, Vite, npm и внешних библиотек.

## Важно

Клиент не начисляет деньги. Победа уходит в `FamilyBankHost.win` / `onResult`. Сумму и лимит 2 раза в сутки считает backend Family Bank.
